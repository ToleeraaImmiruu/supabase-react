
# React + Supabase Product App

A simple product application built with React, Vite, and Supabase. The application fetches product data from a Supabase database and displays product names and prices.

## Features
- Fetch product records from Supabase
- Display product names and prices
- Loading state while fetching data
- Error handling for database requests
- Responsive foundation for future improvements

## Technologies Used

- React
- Vite
- JavaScript
- Supabase
- CSS

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd supabase-react
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file in the project root.

Add your own Supabase project URL and publishable key:

```dotenv
VITE_SUPABASE_URL=YOUR_SUPABASE_PROJECT_URL
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

Get these values from your Supabase project settings. Never put a Supabase secret key in frontend code.

### 4. Set up the database

In the Supabase SQL Editor, create the `public.product` table with the required columns.

```sql
create table public.product (
  id bigint generated by default as identity primary key,
  name text not null,
  price numeric(10, 2) not null default 0
);
```

Configure Row Level Security (RLS) and appropriate policies for your use case. For a public product catalog, allow only the intended public read access. Do not expose private data.

### 5. Run the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.
